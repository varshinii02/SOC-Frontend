# FiGHT — 5G Telecom Threat Intelligence

A web-based threat intelligence interface for exploring **FiGHT (5G and Future Generation) tactics and techniques**, with MITRE ATT&CK mappings, mitigations, and detection information.

## 📌 Overview

FiGHT is a threat intelligence framework focused on security threats in **5G and future-generation telecom networks**.

This project provides an interactive interface to explore FiGHT tactics and techniques. Selecting a technique displays its description and retrieves related **MITRE ATT&CK information, mitigations, and detection strategies** through the backend API.

## ✨ Features

- Interactive FiGHT Threat Matrix
- Search techniques by name or technique ID
- Browse techniques under different tactics
- Detailed technique information
- FiGHT technique descriptions and references
- MITRE ATT&CK technique mapping
- MITRE ATT&CK descriptions and links
- Mitigation information
- Detection strategies
- Interactive tactic and technique popups
- REST API integration
- Deployed frontend and backend
